# Screen Recorder

A small Python screen recorder that captures the full screen at 1080p/60fps, saves it to `Recording.avi`, and shows a resizable live preview window while recording.

**Built with:** Python, OpenCV, PyAutoGUI, NumPy

## Run

```bash
pip install opencv-python pyautogui numpy
python MainProgram.py
```

Press **x** in the preview window to stop recording.
